# Mirmir Web

The browser UI is a Leptos CSR application built with Trunk. In addition to the
native Mirmir requirements, install the pinned toolchain's WebAssembly target
and the Trunk bundler:

```sh
rustup target add wasm32-unknown-unknown --toolchain nightly-2026-07-13
cargo install trunk --locked
```

Build the browser bundle from this directory:

```sh
trunk build
```

Use `trunk serve` for isolated frontend development. The native Mirmir build
also invokes Trunk and embeds this bundle in the application binary, so building
the complete runtime requires Trunk and the WebAssembly target. Browser behavior
lives in Rust/Leptos; the JavaScript module in `dist` is generated by
`wasm-bindgen` and must not be edited by hand.
