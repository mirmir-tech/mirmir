# Mirmir Web

The browser UI is a Leptos CSR application built with Trunk. In addition to the
native Mirmir requirements, install the pinned toolchain's WebAssembly target
and the Trunk bundler:

```sh
rustup target add wasm32-unknown-unknown --toolchain nightly-2026-07-13
cargo install trunk --locked
```

Build the browser bundle from this directory:

```sh
trunk build
```

Use `trunk serve` for isolated frontend development. Native Mirmir builds embed
the versioned bundle from `src/web/dashboard` and do not require Trunk. Set
`MIRMIR_REBUILD_DASHBOARD=1` when a native build should first rebuild and embed
the browser sources. Browser behavior lives in Rust/Leptos; the JavaScript
module in `dist` is generated by `wasm-bindgen` and must not be edited by hand.

## Tests

State that decides what the dashboard shows and sends is plain Rust with
native unit tests:

```sh
cargo test
```

Browser tests mount components in headless Firefox (or Chrome) with a
stand-in for the server's HTTP API and check what the page shows and the
requests it sends. They need the `wasm-bindgen-test-runner` of the
`wasm-bindgen` version in `Cargo.lock` and a WebDriver:

```sh
cargo install wasm-bindgen-cli --locked --version \
  "$(cargo pkgid wasm-bindgen | sed 's/.*@//')"
CARGO_TARGET_WASM32_UNKNOWN_UNKNOWN_RUNNER=wasm-bindgen-test-runner \
  GECKODRIVER=$(command -v geckodriver) \
  cargo test --target wasm32-unknown-unknown
```

After changing the browser sources, rebuild the bundle with `trunk build
--release` and copy `dist/index.html`, `dist/mirmir-dashboard.js` and
`dist/mirmir-dashboard_bg.wasm` to `../src/web/dashboard`.
