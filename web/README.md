# Mirmir Web

The browser UI is a Leptos CSR application built with Trunk. In addition to the
native Mirmir requirements, install the pinned toolchain's WebAssembly target
and the Trunk bundler:

```sh
rustup target add wasm32-unknown-unknown --toolchain nightly-2026-07-13
cargo install trunk --locked
```

Build the browser bundle from this directory:

```sh
trunk build
```

Use `trunk serve` for isolated frontend development. Native Mirmir builds embed
the versioned bundle from `src/web/dashboard` and do not require Trunk. Set
`MIRMIR_REBUILD_DASHBOARD=1` when a native build should first rebuild and embed
the browser sources. Browser behavior lives in Rust/Leptos; the JavaScript
module in `dist` is generated by `wasm-bindgen` and must not be edited by hand.
